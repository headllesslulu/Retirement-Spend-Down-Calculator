# 🧮 Retirement Spend-Down Calculator (PWA)

A free, installable **Progressive Web App (PWA)** that helps middle-class retirees model their financial future using a “Spend Well, Transition Smoothly” strategy.

📈 **Visualize how long your liquidity will last.**  
📉 **See when you may qualify for Medicaid.**  
🏡 **Preserve your home and simulate realistic Social Security income.**

## ✨ Features

- ✅ Retirement age and liquidity inputs
- ✅ Adjustable inflation and return assumptions
- ✅ Social Security income simulation
- ✅ Medicaid eligibility modeling
- ✅ Chart.js-based visualization
- ✅ Fully installable PWA (Add to Home Screen)
- ✅ Offline-capable via service worker

---

## 🛠 How It Works

The app projects your portfolio balance from retirement until age 90, accounting for:

- Spending needs (inflation-adjusted)
- Social Security income (starting age 67)
- Investment return (compounding annually)
- Medicaid trigger when assets fall below $2,000
